# CVHS Flight School Question Bank

This build contains **240 question records for every FAA PHAK chapter, Chapters 1–17 (4,080 records total)**.

Each record is machine-readable and includes chapter, topic, subtopic, difficulty, question type, four answer choices, correct answer index, explanation, chapter source reference, learning objective, and question family.

The quiz engine selects 20 questions per attempt using topic-balanced selection, avoids recently seen question IDs where possible, and supports unlimited attempts. Question families are used to reduce same-concept repetition within an attempt.

## Content QA note
The bank is an extensive course bank built from chapter concepts and question families. Because this is a very large generated assessment set, it should be treated as a curriculum bank requiring instructor/club review before being represented as an official FAA test bank. It is not an FAA-published question bank.
