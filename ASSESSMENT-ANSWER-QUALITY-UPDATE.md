# Assessment answer-quality update

This release preserves the 17 chapters, 510 questions, keyed correct indices, explanation fields, and quiz shuffle logic.

The conspicuous pattern in which a short correct label is surrounded by incorrect choices with explanatory `because` clauses has been normalized for 76 automatically revised questions, plus a manually revised continuation-bias question in Chapter 2. Where feasible, the explanatory tails were removed from distractors rather than inventing new claims or changing the keyed answer. This includes Chapter 2, question 15: Detect / Estimate / Choose / Identify.

The assessment validation checks unique IDs, four distinct options, answer indexes, 17 reflections, and some answer-length bias. All 510 questions pass structural validation.

IMPORTANT: This is a targeted wording normalization, not a professional psychometric review of all 510 questions. Remaining answer-length differences and semantic clues are possible; item-by-item educator review and student pilot testing are recommended before high-stakes use. Existing question explanations are still shown after grading, not as part of answer options.
